A NEW RESPONSIBILITY - GILBERT ELEMENTARY
The Wild Robot chapters 25-32 - iPad-friendly classroom adventure

What is included:
- index.html: The entire game. No external scripts, assets, or accounts required.
- Eight chapter missions: The Egg, The Performer, The Gosling, The Old Goose,
  The Beavers, The Nest, The First Night, The Deer.
- Touch-friendly exploration, action challenges, caring decisions, and 40 questions.
- 30-minute session: extra mixed reading and forest challenges continue until the timer reaches 30 minutes.
- Browser-based progress saved on the individual iPad.

Publish on GitHub Pages:
1. Sign in at https://github.com and create a PUBLIC repository. Suggested
   repository name: wild-robot-new-responsibility
2. Select Add file > Upload files and upload index.html to the repository ROOT.
3. Commit changes.
4. Go to Settings > Pages. Under Build and deployment choose
   Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
5. Your game URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/wild-robot-new-responsibility/
6. Open that URL in Safari on your school iPads. Landscape recommended.

Important: Students' progress stays on each browser/device; it is not a roster
or teacher dashboard. In a shared iPad, use Reset to start another game.

Original educational classroom project inspired by the themes of
